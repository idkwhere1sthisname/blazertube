# Install BlazerTube

To install BlazerTube, you must have a homebrewed console with LumaCFW and Pretendo installed. If yours isn't already, please follow [this guide](https://3ds.hacks.guide).

Select your YouTube app's region and then download its respective code.ips (usually it's the same as the console's region)

You must place the code.ips file in different folders depending on the app's region:

Europe: `/luma/titles/00040000000CCD00/`

USA: `/luma/titles/00040000000B0F00/`

Japan: `/luma/titles/00040000000D3000/`

If the folder of the region you're trying to use doesn't exist, simply create the directory and place code.ips there.

Once done, boot your console while holding SELECT and make sure "Enable Game Patching" is enabled, then open YouTube.

Please note that BlazerTube is still in beta and things may not work as intended (e.g. slow videos, captions not working, crashes in general. Please refer to the #known-bugs channel in our Discord server for more information)

If the code.ips patch changes (e.g. embedded HTML edit), you will be notified in the Discord server

The patches are intended for the latest YouTube version (v2096 USA/JPN, v2080 EUR). You can find it on hShop.

You must be on Pretendo when using BlazerTube.
