# Install Hulu Plus

> [!NOTE]
> The Hulu Plus app does not have any functionality, it also errors out with 002-0110 every 2-3 seconds

To install the Hulu Plus patch, you must have a homebrewed console with LumaCFW. If yours isn't already, please follow [this guide](https://3ds.hacks.guide).

Select your app's region and then download its respective code.ips (usually it's the same as the console's region)

You must place the code.ips file in different folders depending on the app's region:

USA: `/luma/titles/0004000000081700/`

Japan: `/luma/titles/00040000000FC400/`

If the folder of the region you're trying to use doesn't exist, simply create the directory and place code.ips there.

Once done, boot your console while holding SELECT and make sure "Enable Game Patching" is enabled, then open YouTube.

The patches are intended for the latest app version (v0 USA, v32 JPN). You can find it on hShop.
